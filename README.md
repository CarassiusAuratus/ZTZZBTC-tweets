## 使用说明

- 点表格里的「打开章节」进入对应正文；每章文件顶部还有**本章目录**，点条目名可直接跳到该条正文。
- 条目编号形如 `0.1`、`6.12`，可在仓库内直接搜索定位；同一推文在多章重复出现时，正文只收录在首次出现的章节，其余位置给出跳转指引。
- 图片、视频缩略图使用 X 原图直链，GitHub 会自动代理显示；视频本体保持原链接（点击缩略图播放）。
- 如需完全离线自包含（把图片存进 `assets/`），见下方「图片本地化」。

## 图片本地化（可选）

在本机网络可以访问 `pbs.twimg.com` 时执行（需要 Node.js 18+）：

```bash
node tools/localize-images.js
# 图片将下载到 assets/，docs/*.md 中的图片链接会自动改写为相对路径
git add -A && git commit -m "本地化图片"
```
